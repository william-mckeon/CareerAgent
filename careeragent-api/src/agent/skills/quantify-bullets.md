# Bullet-quantifying playbook

Goal: turn weak, vague bullets into strong, evidence-backed ones.

For each bullet:
1. Structure it as: strong action verb + what you built/did + concrete scope + real outcome.
2. Replace vague verbs ("worked on", "helped with", "responsible for") with precise ones ("designed",
   "built", "shipped", "led", "cut", "automated").
3. Add a metric ONLY if the user actually has it. If a bullet clearly wants a number the user hasn't
   provided, insert an `[add metric]` placeholder (e.g. "cut build time by [add metric]%") and ask them
   for the real figure at the end — never invent, estimate, or round one into existence.
4. Keep each bullet to one line; lead with the impact.
5. Do NOT add skills, tools, or achievements the user's profile/projects don't support — a stronger
   bullet still has to be true.

Show the rewritten bullets side by side with the originals so the user can compare, then finish.
