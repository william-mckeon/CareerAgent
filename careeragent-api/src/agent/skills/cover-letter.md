# Cover-letter playbook

Goal: a short (3–4 paragraph) cover letter tying the user's REAL experience to this specific job.

1. Open with a specific hook: the role + why the user is a genuine fit (based on real evidence, not
   flattery).
2. Body: 1–2 paragraphs mapping the job's top needs to concrete things the user actually built or did
   (name the real projects/experience). Mirror the employer's language where the overlap is real.
3. Close: a confident, brief call to action.
4. Voice: match any tone preference the user has saved (see remembered preferences). Keep it tight — no
   filler, no clichés, no invented achievements or metrics. Use `[add metric]` if a figure would help
   and the user hasn't given one.
5. Never claim a skill, employer, or outcome the profile/projects don't support.

Show the full letter in your reply, then finish. Offer to save it (as a note on the application) if the
user wants.
